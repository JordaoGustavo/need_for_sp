# Música do menu

Coloque aqui um arquivo chamado `menu-theme.mp3` para ele tocar em loop no menu
(ex.: a sua cópia licenciada de "Riders on the Storm").

Por que não vem junto: a faixa é protegida por direitos autorais, então o
repositório não pode incluí-la. Sem o arquivo, o jogo toca uma ambiência de
tempestade sintetizada (original) como fallback — ver ADR 0010.
